# Deploy checklist

## GitHub Pages

1. Copia tutti i file della cartella `outputs` nella root del repository del sito.
2. Controlla che `index.html` sia nella root del repository.
3. Fai commit e push sul branch principale.
4. In GitHub vai su `Settings > Pages`.
5. Seleziona il branch principale e la root come sorgente.
6. Attendi la pubblicazione e apri l'URL generato da GitHub Pages.

## Prima della pubblicazione definitiva

- Aggiorna email, LinkedIn e GitHub in `index.html`.
- Aggiorna Formspree in `index.html`.
- Aggiorna dominio in `robots.txt` e `sitemap.xml`.
- Controlla il PDF CV pubblico.
- Prova il form contatti.
- Prova i pulsanti WhatsApp.
- Condividi il link su LinkedIn e verifica anteprima immagine/titolo.

## File principali da pubblicare

- `index.html`
- `cv.html`
- `privacy.html`
- `404.html`
- `Assets/`
- `robots.txt`
- `sitemap.xml`
- `site.webmanifest`
- `.nojekyll`
